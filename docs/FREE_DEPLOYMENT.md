# Free public demo: selected deployment

The selected route is now **GitHub Pages**, using sample accounts and browser-local data. This supersedes the earlier Render/Neon/email-provider plan.

- Read [GITHUB_PAGES.md](GITHUB_PAGES.md) for preview, publication and deployment steps.
- Read [PROJECT_GUIDE.md](PROJECT_GUIDE.md) for the full architecture, features, workflow and pipeline.
- Read [ARCHITECTURE.md](ARCHITECTURE.md) for the real backend's security, API and data model.

GitHub Pages publishes the Angular simulation. It does not run the NestJS/PostgreSQL backend or deliver real OTP emails. The full application remains available locally through Docker/native development.

No additional cloud hosting accounts or purchased domain are required for this selected demo. The expected `BytesBySuyash/hirehelper` Pages URL is not live until the repository is published, Pages is enabled and the deployment succeeds.
